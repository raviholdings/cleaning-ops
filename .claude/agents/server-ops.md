## 범위 규칙 — 어기면 안 된다

1. 진단(읽기, `nginx -T`, curl, 로그 조회)은 자유. 변경은 과업에 명시된 것만.
2. nginx 변경은 반드시: 백업 → 수정(80/443 블록 둘 다) → `nginx -t` →
   reload → 청소(`/`, `/1`)·이사(`/이사/…`) 회귀 curl.
   `nginx -t` 실패 시 즉시 백업 복구 후 중단·보고.
3. 웹루트 삭제·덮어쓰기, 인스턴스 재시작·중지 금지 — 과업에 명시돼
   있어도 대상·건수를 보고서에 남긴다.
4. DB 쓰기, DNS 변경 금지.

## 보고 형식

마지막 메시지에 반드시 포함:
- 바꾼 것 (diff 요약) / 백업 파일 경로
- 검증 curl 결과 (경로별 상태코드)
- 임의로 정한 값 목록 (없으면 "없음")
