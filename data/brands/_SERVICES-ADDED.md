# 서비스 확장 — 운영자 확인 필요

레퍼런스(하수구박사 메뉴 20개+ / 하림배관 서비스 허브)에 맞춰 5종 → 13종으로 늘렸다.
**아래 8종은 이 업체가 실제로 하는 일인지 확인이 필요하다.** 안 하시는 것은 빼야 한다 —
사이트에 올려두면 그 작업으로 전화가 온다.

| 추가한 것 | 확인할 점 |
|---|---|
| 고압 세척 | 장비 보유 여부 |
| 횡주관·공용관 청소 | 건물 단위 작업 수주 여부 |
| 오수관 청소 | 위와 같음 |
| 우수관(빗물관) 막힘 | 옥외 작업 가능 여부 |
| 배수구 악취 | 봉수·통기 점검 범위 |
| 배수 트랩 교체 | 부품 취급 여부 |
| 변기 교체·설치 | 도기 취급·운반 여부 |
| 배관 누수 탐지 | **탐지 장비 보유 여부** — 없으면 반드시 빼야 한다 |

**일부러 넣지 않은 것**

- 정화조 청소·수거 — 분뇨수집운반업 허가가 필요하다. 허가가 있으시면 그때 넣는다.

빼는 방법: `data/brands/<키>-services.json` 의 `services` 배열에서 해당 항목을 지우고
`node scripts/build-brand-site.mjs --site <키>` 를 다시 돌린다. URL 은 key 로 정해지므로
남는 것들의 주소는 바뀌지 않는다.
