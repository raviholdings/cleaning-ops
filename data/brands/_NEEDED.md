## 1. 다섯이 서로 남남으로 보이려면 반드시 달라야 하는 것

지금 색·레이아웃·글꼴·문장·URL 은 전부 갈라놨다. 아래가 겹치면 그게 전부 무의미해진다.

| 항목 | 상태 | 비고 |
|---|---|---|
| **전화번호 5개** | ⛔ 다섯 다 `070-7106-5241` | **가장 큰 구멍.** 착신전환이든 안심번호든 겉으로 달라야 한다 |
| **도메인 5개** | ⛔ 전부 `TBD.co.kr` | 정해지면 `--host` 로 넘긴다. 슬러그 씨앗은 사이트 키라 도메인이 바뀌어도 URL 은 유지된다 |
| **사업자 정보** | ⛔ 푸터에 아무것도 없음 | 상호 · 사업자등록번호 · 대표자 · 주소 × 5 |
| **로고 / 파비콘** | ⛔ 0개 | 탭 아이콘이 전부 기본값이라 5개가 똑같이 보인다 |

## 2. 사진 — 사이트당 8~12장, 합계 40~60장

넣는 곳: `apps/brand-static/<키>-template/assets/img/`
등록: `data/brands/<키>.json` 의 `images.pool`

```json
"images": { "pool": [
  { "file": "dream-01.webp", "label": "변기 이물질 제거", "width": 800, "height": 600 }
]}
```

- **다섯 사이트가 같은 사진을 쓰면 안 된다.** 사진 한 장이 겹치면 역이미지검색으로 바로 묶인다.
- 배관 캐러셀 사진(`apps/piping-static/.../assets/img/`)은 **"다봄배관" 워터마크와 070-7106-5241 이 박혀 있어 재사용 불가**.
- `width`/`height` 는 실제 값으로. 없으면 로딩 중 화면이 덜컹거린다.
- 등록했는데 파일이 없으면 빌드가 멈춘다(깨진 이미지가 258장 나가는 것보다 낫다).
- 풀이 비어 있으면 사진 구역 자체가 안 나온다. 자리표시자를 내보내지 않는다.

## 3. 서비스 상세 페이지 (5종 × 5사이트 = 25장)

변기 막힘 / 하수구 막힘 / 싱크대 막힘 / 세면대·욕조 / 관 내시경

사이트마다 **문장이 하나도 겹치면 안 되므로** 아래를 사이트별로 따로 받는 게 아니라,
**사실 관계를 한 번만 받고 표현을 다섯 갈래로 나눠 쓴다.** 필요한 사실:

- 실제 **작업 순서** — 도착해서 무엇부터 보고, 무슨 장비를 어떤 순서로 쓰는지
- **장비 이름** — 스프링(관통기) 굵기, 고압세척기 압력, 내시경 종류 등 실제로 쓰는 것
- **안 하는 것** — 어떤 상황에서 작업을 안 하고 돌아오는지
- **걸리는 시간** — 단순한 경우 / 깊은 경우
- 그 작업에서 **자주 나오는 질문**

## 4. 작업사례 (사이트당 6~10건, 합계 30~50건)

⚠️ **지금 사이트에 올라가 있는 사례는 제가 지어낸 것이다.** 실제 있었던 일이 아니다.
개별 사례 페이지로 확장하면 지어낸 이야기가 더 늘어난다. **실제 건으로 교체해야 한다.**

건당 필요한 것:

- 사진 (전/후가 있으면 더 좋다)
- 지역 (시·군·구까지만. 상세 주소는 쓰지 않는다)
- 어떤 증상으로 부르셨는지
- 실제 원인이 무엇이었는지
- 어떻게 처리했는지
- 걸린 시간
- 고객 정보는 넣지 않는다 (이름·동호수·연락처)

## 5. 법적으로 지금 비어 있는 것

- **개인정보처리방침 페이지** — 접수폼으로 이름·연락처·주소를 받고 있는데 방침 페이지가 없다.
  동의 전문 모달은 있지만 별도 페이지가 필요하다. **내가 초안을 만들 수 있다** — 사업자 정보만 주면 된다.
- **사업자 정보 표시** — 푸터에 상호·사업자등록번호·대표자·주소.
