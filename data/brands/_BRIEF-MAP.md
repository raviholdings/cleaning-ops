## 브리프대로 가되 지시가 우선하는 것

- **글꼴** — 브리프 2 는 "세리프 또는 고급 디스플레이", 브리프 5 는 "크고 현대적인 산세리프"를
  요구하지만, **다섯 사이트 전부 Noto Sans KR 로 통일**하라는 지시가 나중이므로 그쪽을 따른다.
  고급스러움은 서체가 아니라 굵기·자간·여백으로 낸다.
- **요금** — 브리프에 금액 표기가 없고, 앞서 "보고 나서" 유지로 확정했다. 그대로 간다.

## 브리프가 공통으로 금지한 것 (전부 지킨다)

- 확인되지 않은 **경력·자격증·출동 시간·고객 수·성공률·특허·인증** 생성 금지
- **가짜 고객명·후기·평점·고객사 로고** 생성 금지 → 후기 구역은 데이터가 있을 때만 만든다
- 보유하지 않은 **장비** 표시 금지 → 장비 목록은 운영자 확인 후 채운다
- 제공하지 않는 **무상 보증·최저가·구독 상품·SLA** 금지
- 업체 비교·순위·중개 요소 금지

## 빈 구역 처리 (2026-08-31 확정)

데이터가 없는 구역은 **자리를 잡고 "준비 중"** 으로 표시한다. 지어내지 않는다.

    후기       → "후기 준비 중"
    장비 목록   → "장비 목록 준비 중"
    사업자 정보 → "사업자 정보 준비 중"

⚠️ **공개 전에는 반드시 채우거나 빼야 한다.** "준비 중" 이 붙은 채로 영업하면
준비가 안 된 업체로 보인다. 배포 스크립트에서 이 문구를 검사하도록 만들어 둔다.
