# 랜딩페이지 HTML 수정 의뢰

작업 범위는 `apps/cleaning-ravi/src/` 뿐입니다.

## 절대 건드리지 말 것

1. **소유확인 메타태그** — `src/layouts/Page.astro`
   ```astro
   <meta name="naver-site-verification" content={SITE_CONFIG.naverSiteVerification} />
   ```
   지금 소유확인이 안 끝난 사이트가 1,000개 있습니다. 이 태그가 빠지거나 값이
   고정되면 그 1,000건이 전부 실패합니다.

2. **canonical** — 페이지마다 다른 값이어야 합니다 (`.../82.html` 처럼).
   고정되면 100장이 1장으로 합쳐집니다.

3. **`scripts/` 폴더** — 파이프라인 코드입니다. 열지 마세요.

4. **`src/layouts/Layout.astro`** — 그대로 두되 **import 하지 마세요.**
   빌드 결과물이 잘못 들어간 파일이라 남의 소유확인 토큰이 박혀 있습니다.
   실제 템플릿은 `Page.astro` 입니다.

5. **빌드·배포 금지** — `astro build`, 배포 스크립트 모두 실행하지 마세요.
   HTML 수정만 하고 알려주시면 배포는 따로 진행합니다.

## 할 일 (위에서부터 순서대로)

### 1. 중복 완화 ← 가장 중요
고정 섹션 5개(3대 약속 / 청소 범위 / 서비스 종류 / 확인 사항 / 진행 절차)가
100장 전부 글자까지 똑같습니다. 검색로봇이 100장을 1장으로 봅니다.

지역·키워드에 따라 문장이 달라지게 바꿔주세요.
- 범위: `src/lib/content.ts`(또는 문구가 있는 파일), `[id].astro`, `index.astro`

### 2. 앵커 텍스트
관련 링크가 전부 "호텔청소 안내" 같은 형태로 비슷합니다.
`{지역} {키워드} 업체 비교` 처럼 페이지마다 다르게 바꿔주세요.
- 범위: `[id].astro`, `index.astro`

### 3. og:image 추가
head 의 meta 중 이것만 빠져 있습니다.
- 범위: `Page.astro`

### 4. 푸터 정리
아래 문구를 없애주세요.
```
함께 문의가 많은 키워드: 입주전청소, 입주청소가격, ...
전체 페이지 목록은 사이트맵에서 확인하실 수 있습니다.
```
푸터의 `사이트맵 · RSS` 링크도 같이 빼주세요. head 의
`<link rel="sitemap">` 과 robots.txt 가 있어서 수집에는 지장 없습니다.

### 5. 리뷰 pool

**비교 서비스에 대한 후기**를 여러 개 만들어 두고 페이지마다 다르게 뽑아 보여줍니다.
1번(중복 완화)과 같은 효과를 내므로 사실상 가장 중요한 작업 중 하나입니다.

작성 방향:
- 이름은 `김**`, `이**` 형태
- 한두 문장, 짧게
- 내용 축: ① 저렴하고 빠르게 받았다 ② 잘 설명해주고 좋은 업체를 찾았다
- **메인/서브 키워드에 맞춰 다르게** 쓸 것. 키워드는 `src/lib/keywords.ts` 참고
  (입주청소 / 이사청소 / 준공청소 / 상가청소 / 사무실청소 / 오피스텔청소 /
   인테리어후청소 / 건물청소 / 화장실청소 …)

예시:
```
김**  입주청소  견적 세 군데 비교해보고 제일 싼 곳으로 했어요. 연락도 바로 왔습니다.
이**  이사청소  이사 날짜가 급했는데 당일에 가능한 업체를 찾아주셨어요.
박**  준공청소  준공 일정에 맞춰야 해서 걱정했는데 조건 맞는 곳을 골라주셨습니다.
최**  상가청소  평수랑 상태 물어보고 견적 차이를 설명해줘서 고르기 편했어요.
정**  사무실청소 업체마다 뭐가 다른지 알려주셔서 비교하기 좋았습니다.
```

**⚠️ 구조화 데이터(`AggregateRating`, `Review` schema.org)는 넣지 마세요.**
실제 후기가 아닌데 별점 구조화 데이터를 넣으면 네이버·구글 모두 정책 위반이라
**색인에서 빠집니다.** 지금 색인 0건을 풀려는 상황에서 반대로 가는 일입니다.
화면에 텍스트로만 보여주세요. 별점 아이콘도 구조화 데이터 없이 표시만 합니다.

- 범위: `src/lib/content.ts`, `Page.astro`

### 6. 네이버 지도 / 소링크
**지도는 페이지 하단**에 둡니다.

참고로 지도를 넣어도 네이버 플레이스에는 등록되지 않습니다. 플레이스는
스마트플레이스에 사업자등록증·실주소로 따로 등록해야 하는 별개 시스템입니다.
또 지도 iframe 은 검색로봇이 못 읽습니다(체크리스트의 `Frame Tag` 항목).
**SEO 목적이 아니라 사용자 신뢰용**으로만 넣는 것이라고 보시면 됩니다.

- 범위: `[id].astro`, `index.astro`
